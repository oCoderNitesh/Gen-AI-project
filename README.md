GenAI Knowledge Assistant

A Python-based Generative AI project that answers questions using a knowledge source.

Features

- AI-powered question answering
- Knowledge retrieval
- AI agent and tools
- Streamlit user interface
- git & github

Technologies

- Python
- Streamlit
- ChromaDB
- LLM API

Setup

1. Install dependencies using "pip install -r requirements.txt".
2. Configure the required API key in a local ".env" file.
3. Run the application using "streamlit run app_ui.py".

Project Files

- "app.py" — Basic AI application
- "agent.py" — Agent logic
- "knowledge_assistant.py" — Knowledge assistant
- "requirements.txt" — Project dependencies
